# 语言策略

## 定位

Pi Agent from Zero 面向中文学习者，简体中文是核心教学内容的事实源。英文入口用于帮助国际贡献者理解项目定位、运行项目和参与协作。

## 使用规则

| 内容 | 主要语言 |
|---|---|
| README 与课程讲义 | 简体中文 |
| 英文项目入口 | 英文，与中文 README 的发布级信息保持同步 |
| 代码标识符、公共 API、协议字段 | 英文 |
| 必要的代码注释 | 优先英文；教学快照可使用中文解释复杂概念 |
| Commit message | 英文 Conventional Commits |
| Issue、Discussion、Pull Request | 中文或英文均可 |
| Release Notes | 中文为主，附英文摘要 |

## 同步要求

每次正式版本发布时，以下内容必须在中英文 README 中一致：

- 当前版本和项目状态
- 安装与运行命令
- 能力边界和安全提示
- Roadmap 链接
- 作者、上游署名和许可证

完整课程不要求逐字翻译成英文。英文内容不能反向改变中文教学结论；发生差异时，以中文讲义及其源码证据为准。
