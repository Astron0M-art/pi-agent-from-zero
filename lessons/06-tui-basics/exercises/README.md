# 练习

## A. 光标移动

实现 `InputBuffer.move_left()` 和 `move_right()`，先写边界测试。不要修改内部字段绕过不可变状态。

## B. 卡片折叠

给 `ToolCard` 增加 `expanded`。折叠时只显示状态、名称和参数；展开后再显示结果。Reducer 只改变状态，Renderer 决定布局。

## C. 显示宽度

研究为什么 `len("中") == 1`，但多数终端占两列。设计一个 `visible_width()` 接口和中文/emoji 测试，不要求在本版引入第三方依赖。

## 验收

- 事件事实与显示策略仍分离；
- 旧测试全部通过；
- 失败时已有信息不丢失；
- 文档明确教学版与 Pi 的差异。
