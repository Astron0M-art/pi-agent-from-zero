# 理解检验参考答案

1. 它包含截断、标签和卡片等显示选择，回填会污染模型上下文并重复工具信息。
2. 增量是构建过程，Completed 是权威最终快照；两者都追加会重复。
3. 工具错误是模型可恢复的观察，模型可能换参数或换工具；只有 `AgentFailed` 才是运行终止事实。
4. 能证明纯文本布局、视口预算和内容存在；不能证明真实终端的列宽、颜色、IME、键位或差分重绘正确。
5. 保存消息/事件等事实记录，恢复时重新投影；帧只是特定尺寸和主题下的派生结果。

## 光标移动参考

`move_left` 使用 `max(0, cursor - 1)`，`move_right` 使用 `min(len(text), cursor + 1)`，并返回新的 `InputBuffer`。中文在 Python 字符索引下可工作，但复杂 emoji 的 grapheme 移动仍未解决。
