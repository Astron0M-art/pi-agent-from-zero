# 理解检验参考答案

1. 只读不等于可读取任意数据；项目外可能包含密钥、个人文件和其他仓库。
2. 否则非法请求也会打扰用户，错误的处理器甚至可能在审批前产生副作用。
3. 它保证本次替换目标不歧义；不保证语义正确、并发安全、原子写入或改动符合用户意图。
4. Bash 可以绕过 Python 文件工具的路径约束，并启动任意子进程，因此能力与风险都更大。
5. 截断是模型上下文投影，不是文件变更；覆盖原文件会把显示预算错误地变成数据损坏。

## offset 实现提示

在 Schema 增加可选 `integer`，读取后先 `splitlines(keepends=True)`，校验 `1 <= offset <= len(lines)`，再从 `offset - 1` 拼接。Registry 截断仍保留为最终兜底。提示中使用实际保留行数计算下一 offset，并为无末尾换行文件单独写测试。

## head/tail 提示

不要把列表反转后忘记恢复顺序。先写：输入 `1..20`，head 包含 `1` 不含 `20`，tail 包含 `20` 不含 `1`；然后再处理字符预算。

## Operation 设计提示

可以使用冻结 dataclass：`tool_name`、`action`、`target`、`writes_state`。审批器消费结构化事实，UI 再负责渲染文本；不要让权限规则解析自然语言提示。
